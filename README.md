# ClaudeCode Games

A collection of interactive web-based games built with HTML, CSS, and JavaScript.

## Games

### Tic Tac Toe
- Play against an AI opponent powered by the minimax algorithm
- Clean, modern UI with light/dark mode support
- New Game button to reset and play again
- File: `tic-tac-toe.html`

### Minesweeper
- Classic minesweeper gameplay with three difficulty levels:
  - **Easy**: 8×8 grid with 10 mines
  - **Medium**: 12×12 grid with 30 mines
  - **Hard**: 16×16 grid with 40 mines
- University of Pittsburgh blue and gold color scheme
- Left-click to reveal cells, right-click to flag mines
- Built-in timer and mine counter
- File: `minesweeper.html`

## How to Play

1. Open any `.html` file in your web browser
2. Play directly - no installation required
